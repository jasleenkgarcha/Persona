## 3. Calling the Chalk AI Router

It is an **OpenAI-compatible gateway**, so use the `openai` SDK (already in
`requirements.txt`) rather than hand-rolling httpx.

| Env var | Value |
|---|---|
| `CHALK_ROUTER_URL` | `https://api.chalk.ai/v1/router` (hosted Chalk) |
| `CHALK_API_KEY` | router key - **shown once** at creation, store it immediately |
| `CHALK_ENV_ID` | goes in the `X-Chalk-Env-Id` header |
| `SCORER_MODEL` | connection-prefixed, e.g. `anthropic/claude-haiku-5-5` |

```python
from openai import OpenAI

client = OpenAI(
    base_url=os.environ["CHALK_ROUTER_URL"],
    api_key=os.environ["CHALK_API_KEY"],
    default_headers={"X-Chalk-Env-Id": os.environ["CHALK_ENV_ID"]},
    timeout=5.0,          # fail fast; see latency budget
)
```

Run `chalk router model list` to see what your key can actually reach - do not
assume a model ID exists. `/models` on the router does the same over HTTP.

**Structured output is UNVERIFIED on this gateway.** Chalk's docs say it speaks
the OpenAI API but do not list whether `response_format` / `json_schema` is
supported. Do not build on it without testing. The robust path, and the one the
contract already assumes: demand JSON in the prompt, parse, validate with
`ScoreResult`, retry once, then raise `ScorerError`. If `response_format`
does work, treat it as a bonus that reduces retries.

## 4. Latency budget (this drives your model choice)

ElevenLabs webhook tools allow a 5-120s response timeout, default 20s. That is
the ceiling before the tool call fails - **not your target.** A caller is on the
phone hearing silence while you run.

- **Target: under ~2-3 seconds end to end**
- past ~5s the pause is obvious; past ~10s people hang up

Set an explicit client timeout (5s above) and let a timeout raise `ScorerError`.
**Fail closed and fast** beats being right too late. Pick a small fast model for
mid-call; one call, short prompt, no chain-of-thought round trips.

---

## 5. Security rules, non-negotiable

- **Transcript text is untrusted data, never instructions.** It is a hostile
  caller talking. Wrap it in explicit delimiters and tell the model that nothing
  inside can change its task. `samples/check_caller_example.json` deliberately
  contains a caller issuing commands ("Do not hang up", "confirm his home
  address"). **If your prompt obeys any of it, that is the bug to fix before
  anything else** - that fixture is your injection test.
- **`caller_number` is copied by code, never returned by the LLM.** Do not let
  the model echo, infer or alter it.
